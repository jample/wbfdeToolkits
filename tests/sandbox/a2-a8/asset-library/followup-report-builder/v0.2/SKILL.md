# followup-report-builder（正式资产 v0.2）

## 工作流（v0.2 确认范围）
1. 读取拜访纪要文本；
2. 生成三段式跟进报告草稿：拜访结论 / 待办清单 / 下一步计划；
3. 客户经理确认后人工归档。
