# SCN-FOLLOWUP-REPORT 场景需求（蓝湾家居，合成夹具）

## 1. 场景概述
- 主体：客户经理
- 触发：拜访完成后客户经理录入拜访纪要
- 起点：拜访纪要文本
- 终点：生成跟进报告草稿，客户经理确认后归档并触发首次跟进行动
- 业务结果：跟进报告当日完成率提升

## 2. 主流程
1. 客户经理口述/录入拜访纪要；
2. 调用 `followup-report-builder` Skill 生成跟进报告草稿（含待办与负责人建议）；
3. 客户经理人工确认待办负责人与日期；
4. 报告归档；数据同步脚本 `source-code/bb_data_sync.py` 定期把报告同步到蓝湾 BI（脚本由前外包商交付，许可情况不明）。

## 3. 人工边界
- 跟进行动的负责人和日期必须由客户经理确认，AI 只建议。

## 4. 依赖
- Skill `followup-report-builder`（客户版）；脚本 `bb_data_sync.py`（权利待确认）
