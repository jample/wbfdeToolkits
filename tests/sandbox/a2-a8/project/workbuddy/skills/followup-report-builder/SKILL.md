# followup-report-builder（蓝湾家居客户版，本项目增量）

## 与正式资产 v0.2 的差异（本项目增量）
1. 新增"待办负责人建议"段落：根据纪要中的事项建议负责人（仍需客户经理确认）；
2. 新增 CRM 回写步骤：确认后的报告通过蓝湾 CRM MCP 写回客户跟进记录；
3. 输出模板从三段式扩展为四段式（新增"风险与升级"段）。

## 工作流
1. 读取拜访纪要文本；
2. 生成四段式跟进报告草稿：拜访结论 / 待办与负责人建议 / 风险与升级 / 下一步计划；
3. 客户经理确认待办负责人与日期后写回蓝湾 CRM。

## 人工边界
- 负责人与日期 AI 只建议，客户经理确认后才生效。
