# 场景复用指南

| 元数据 | 值 |
|---|---|
| Scene ID | SCN-INQ-SUMMARY |
| 场景名称 | 新询盘客户摘要 |
| 所属资产包 | pkg-sales-side-scenes-v1-candidate |
| 编制日期 | 2026-09-14 |
| 复用状态 | 待脱敏与评审 |

## 1. 如何选择本场景和共享资产

| 问题 | 说明 |
|---|---|
| 本场景适合什么业务任务 | 新询盘/新客户出现后需要快速形成内部摘要 |
| 需要同时选用哪些共享资产 | `shared/workbuddy/skills/customer-brief-summary/`（必选） |
| 什么情况下不应复用本场景 | 客户无 CRM 或客户主档不可读；需要 AI 自动回复询盘（禁止动作） |

## 2. 复制或引用哪些 WorkBuddy 内容

| 内容 | 路径 | 复制/引用方式 |
|---|---|---|
| customer-brief-summary Skill | `../../shared/workbuddy/skills/customer-brief-summary/SKILL.md` | 引用共享版本，不复制副本 |

## 3. 如何填写客户覆盖

| 覆盖项 | 对应变量/文件 | 填写说明 |
|---|---|---|
| 客户术语 | `${brief_title}` | 摘要抬头 |
| 角色称谓 | `${sales_role_name}` | 销售角色称谓 |
| 目录 | `${customer_data_root}` | 客户资料根目录 |
| 输出格式 | `${brief_section_titles}` | 摘要分段 |
| Prompt 变量 | 见共享 Skill SKILL.md 变量表 | 逐项填写 |
| MCP 配置占位 | 参考 SCN-VISIT-PREP 集成说明 | 本场景未单独归档 |

## 4. 需要重新开展客户需求确认的内容

| 内容 | 原因 |
|---|---|
| 摘要分段与抬头 | 每个客户的信息关注点不同 |
| 跟进决定的责任人 | 属人工决定权，须客户确认 |

## 5. 怎样利用 fde-deliver 生成新客户交付材料

| 步骤 | 说明 |
|---|---|
| 1 | 将本场景定义、蓝图与覆盖模板交给 `fde-deliver` |
| 2 | 由 `fde-deliver` 生成客户版场景说明与培训材料 |

## 6. 资产核心调整边界

| 变化类型 | 处理方式 |
|---|---|
| 属于客户覆盖范围的变化 | 变量值、分段标题、目录 —— 直接填覆盖模板 |
| 属于资产核心调整、必须提交专业 FDE/资产 Owner 的变化 | 摘要事实边界、不外发边界、共享 Skill 工作流 |
