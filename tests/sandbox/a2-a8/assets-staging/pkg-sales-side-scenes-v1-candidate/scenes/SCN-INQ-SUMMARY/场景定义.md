# 场景定义：SCN-INQ-SUMMARY 新询盘客户摘要（通用版）

> 由客户项目场景需求抽象而来；客户专属术语、目录与结论已移除，转为 `enablement/客户覆盖模板.md` 中的变量。

| 字段 | 内容 |
|---|---|
| 主体 | ${sales_role_name}（销售角色，客户覆盖变量） |
| 触发 | CRM 中出现新询盘记录 |
| 起点 | 收到新询盘提醒 |
| 终点 | ${sales_role_name} 确认一页客户摘要并决定是否跟进 |
| 业务结果 | 缩短新客户的资料汇总时间，减少人工翻查 |

## 主流程（通用）
1. 从 CRM 拉取新询盘与客户主档；
2. 调用共享 Skill `customer-brief-summary` 生成一页摘要；
3. ${sales_role_name} 人工确认摘要；
4. 确认后在 CRM 标记"已摘要"。

## 人工边界
- 是否跟进由人决定，AI 不自动承诺回复客户。
