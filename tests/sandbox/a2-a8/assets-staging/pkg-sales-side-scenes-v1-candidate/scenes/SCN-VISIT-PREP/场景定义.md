# 场景定义：SCN-VISIT-PREP 销售拜访准备（通用版）

> 由客户项目场景需求抽象而来；客户专属术语、目录、人员与审批策略已移除，转为 `enablement/客户覆盖模板.md` 中的变量。

| 字段 | 内容 |
|---|---|
| 主体 | ${sales_role_name}（销售角色，客户覆盖变量） |
| 触发 | 拜访日程临近（提前量可配置，如前一天固定时点） |
| 起点 | 读取 CRM 客户资料与历史跟进 |
| 终点 | 生成拜访简报，${approval_role_name} 审批通过后可用 |
| 业务结果 | 压缩拜访准备时间，统一简报质量 |

## 主流程（通用）
1. 调用共享 Skill `customer-brief-summary` 汇总客户资料；
2. 调用拜访简报 Prompt（`workbuddy/prompts/visit-brief-prompt.md`）生成简报草稿；
3. ${sales_role_name} 核对；${approval_role_name} 审批（审批要求属客户覆盖变量，默认保留人工审批环节）；
4. 简报存入 ${customer_data_root}${customer_id}/visits/（目录为客户覆盖变量）。

## 人工边界
- 价格与折扣信息只展示、不生成承诺；
- 简报未经人工审批不得发送给客户。
