# 场景复用指南

| 元数据 | 值 |
|---|---|
| Scene ID | SCN-VISIT-PREP |
| 场景名称 | 销售拜访准备 |
| 所属资产包 | pkg-sales-side-scenes-v1-candidate |
| 编制日期 | 2026-09-16 |
| 复用状态 | 待脱敏与评审 |

## 1. 如何选择本场景和共享资产

| 问题 | 说明 |
|---|---|
| 本场景适合什么业务任务 | 销售拜访前需要基于 CRM 资料快速生成结构化简报 |
| 需要同时选用哪些共享资产 | `shared/workbuddy/skills/customer-brief-summary/`（必选，步骤 1 依赖） |
| 什么情况下不应复用本场景 | 客户无 CRM 或资料不可读；客户要求 AI 自动发送简报或自动生成价格承诺（禁止动作，须重新设计） |

## 2. 复制或引用哪些 WorkBuddy 内容

| 内容 | 路径 | 复制/引用方式 |
|---|---|---|
| customer-brief-summary Skill | `../../shared/workbuddy/skills/customer-brief-summary/SKILL.md` | 引用共享版本，不复制副本 |
| visit-brief-prompt | `workbuddy/prompts/visit-brief-prompt.md` | 复制到客户项目后按覆盖模板填变量 |
| CRM MCP 配置说明 | `integration/mcp-configuration-guide.md` | 复制说明，按 §4 变量填写 |
| CRM MCP 合成配置模板 | `integration/configuration-templates/crm-mcp.template.yaml` | 复制模板，替换占位变量 |

## 3. 如何填写客户覆盖

| 覆盖项 | 对应变量/文件 | 填写说明 |
|---|---|---|
| 客户术语 | `${brief_section_titles}`、`${brief_title}` | 简报分段与抬头 |
| 角色称谓 | `${sales_role_name}`、`${approval_role_name}` | 销售与审批角色称谓，不填真实人名 |
| 目录 | `${customer_data_root}` | 客户资料根目录 |
| 输出格式 | `${document_style}` | 文书风格 |
| Prompt 变量 | 见 `workbuddy/prompts/visit-brief-prompt.md` 归档说明 | 逐项填写；事实边界与审批边界不可删 |
| MCP 配置占位 | `integration/mcp-configuration-guide.md` §4 | 服务地址、租户、环境变量名、字段映射 |

## 4. 需要重新开展客户需求确认的内容

| 内容 | 原因 |
|---|---|
| 价格展示策略 `${price_display_policy}` | 原客户策略值已排除，每个客户须重新确认可展示边界 |
| 审批角色与审批要求 | 属人工决定权，须客户确认 |
| 简报分段结构 | 每个客户关注点不同 |

## 5. 怎样利用 fde-deliver 生成新客户交付材料

| 步骤 | 说明 |
|---|---|
| 1 | 将本场景定义、蓝图、Prompt、MCP 说明与覆盖模板交给 `fde-deliver` |
| 2 | 由 `fde-deliver` 生成客户版场景交付说明与培训材料 |

## 6. 资产核心调整边界

| 变化类型 | 处理方式 |
|---|---|
| 属于客户覆盖范围的变化 | 变量值、分段标题、目录、风格、审批提示语 —— 直接填覆盖模板 |
| 属于资产核心调整、必须提交专业 FDE/资产 Owner 的变化 | 事实边界、"未审批不发送"边界、价格不承诺边界、共享 Skill 工作流、MCP 工具的人工边界 |
