# 场景复用指南

| 元数据 | 值 |
|---|---|
| Scene ID | SCN-FOLLOWUP-REPORT |
| 场景名称 | 拜访后跟进报告 |
| 所属资产包 | pkg-sales-side-scenes-v1-candidate |
| 编制日期 | 2026-09-16 |
| 复用状态 | 待脱敏与评审 |

## 1. 如何选择本场景和共享资产

| 问题 | 说明 |
|---|---|
| 本场景适合什么业务任务 | 拜访/沟通后需要快速形成结构化跟进报告并明确待办责任 |
| 需要同时选用哪些共享资产 | 无 shared 资产；核心 Skill 为更新候选 `update-candidates/followup-report-builder/v0.3-candidate/`（须经资产 Owner 评审） |
| 什么情况下不应复用本场景 | 客户要求 AI 自动指派责任人或自动对外发送跟进承诺（禁止动作，须重新设计） |

## 2. 复制或引用哪些 WorkBuddy 内容

| 内容 | 路径 | 复制/引用方式 |
|---|---|---|
| followup-report-builder（更新候选） | `../../update-candidates/followup-report-builder/v0.3-candidate/SKILL.md` | 引用更新候选；资产 Owner 决定与正式 v0.2 的关系后按决定执行 |
| CRM MCP 配置说明（可选写回） | `../SCN-VISIT-PREP/integration/mcp-configuration-guide.md` | 参考引用，按客户环境填写 |

## 3. 如何填写客户覆盖

| 覆盖项 | 对应变量/文件 | 填写说明 |
|---|---|---|
| 客户术语 | `${report_section_titles}` | 报告分段标题 |
| 角色称谓 | `${sales_role_name}` | 销售角色称谓，不填真实人名 |
| 目录 | `${report_archive_location}` | 报告归档位置 |
| 输出格式 | `${report_section_titles}` | 分段结构 |
| Prompt 变量 | 见更新候选 SKILL.md 变量说明 | 逐项填写；人工确认边界不可删 |
| MCP 配置占位 | 参考 SCN-VISIT-PREP 集成说明 | 写回为可选能力 |

## 4. 需要重新开展客户需求确认的内容

| 内容 | 原因 |
|---|---|
| 待办负责人的决定权归属 | 属人工决定权，须客户确认 |
| 是否启用 CRM 写回及写回范围 | 原项目的独立同步方案已排除，须重新设计确认 |

## 5. 怎样利用 fde-deliver 生成新客户交付材料

| 步骤 | 说明 |
|---|---|
| 1 | 将本场景定义、蓝图、更新候选 Skill 与覆盖模板交给 `fde-deliver` |
| 2 | 由 `fde-deliver` 生成客户版场景交付说明与培训材料 |

## 6. 资产核心调整边界

| 变化类型 | 处理方式 |
|---|---|
| 属于客户覆盖范围的变化 | 变量值、分段标题、归档位置 —— 直接填覆盖模板 |
| 属于资产核心调整、必须提交专业 FDE/资产 Owner 的变化 | "负责人由人确认"边界、报告事实边界、与正式 v0.2 的合并/版本决策 |
