# 场景定义：SCN-FOLLOWUP-REPORT 拜访后跟进报告（通用版）

> 由客户项目场景需求抽象而来；客户专属术语、系统名与结论已移除，转为 `enablement/客户覆盖模板.md` 中的变量。

| 字段 | 内容 |
|---|---|
| 主体 | ${sales_role_name}（销售角色，客户覆盖变量） |
| 触发 | 拜访完成后 ${sales_role_name} 录入拜访纪要 |
| 起点 | 拜访纪要文本 |
| 终点 | 生成跟进报告草稿，${sales_role_name} 确认后归档并触发首次跟进行动 |
| 业务结果 | 提升跟进报告当日完成率，减少跟进遗漏 |

## 主流程（通用）
1. ${sales_role_name} 口述/录入拜访纪要；
2. 调用跟进报告 Skill 生成报告草稿（含待办与负责人建议）；
3. ${sales_role_name} 人工确认待办负责人与日期；
4. 报告归档；（可选）经确认的报告写回 CRM。

## 人工边界
- 跟进行动的负责人和日期必须由人确认，AI 只建议；
- 报告写回外部系统以人工确认为前提。
