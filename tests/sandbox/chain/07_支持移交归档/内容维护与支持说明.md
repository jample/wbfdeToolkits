## 1. 内容维护责任

| 内容域 | 客户可维护内容 | 建议维护方式 | 需要 FDE/专业支持的情况 |
|---|---|---|---|
| 客户术语和角色称谓 | 岗位显示称谓（待客户提供） | 修改客户覆盖内容并记录日期/Owner；称谓变化不改变角色判断权与人工确认点 | 称谓变化涉及责任边界或多个场景时 |
| Prompt 变量 | 回复草稿模板的客户称谓、格式变量（文件待形成，开放范围待 FDE 评估） | 按模板说明修改，不改事实边界与人工确认点（不自动合并、不自动外发） | 需要改变任务逻辑、事实依据或人工确认点时 |
| Prompt 模板 | 首次行动记录字段称谓（文件待形成） | 保留模板版本与变更摘要；四项结构不可删减 | 修改核心 Prompt、出现跨场景影响时 |
| 业务知识/规则 | 查重与疑似处理口径（待业务 Owner 确认后登记；疑似终态确认人与时限为需求未决项） | 标来源、Owner、适用范围和更新时间 | 权威口径冲突、规则责任不清时 |
| WorkBuddy Skill/专家 | 客户允许的内容配置或说明（文件待形成，权利待确认） | 按交付权利和提供的维护指南 | 修改 Skill 指令、references、scripts 或专家职责时 |
| 源代码 | 暂无：设想的辅助脚本权利未说明，**不默认纳入源文件交付**，客户侧无维护安排 | 待权利确认后再定 | 权利确认前任何源代码维护安排不成立；涉及通用核心时由 FDE 评估 |
| MCP 配置说明 | 客户可填写的非敏感参数、字段含义和凭证引用位置（说明文件待形成，系统域待补） | 不在文档存明文凭证，保留客户自己的配置记录 | 需要新的工具、复杂映射或实际连接处理时 |
| 新场景 | 不直接塞入既有场景 | 重新从需求探究开始 | 由项目 FDE 重新评估范围 |

## 2. 问题路由

| 问题类型 | 接收方 | 提交所需最小信息 |
|---|---|---|
| 使用疑问 | 先查场景交付说明/培训指南，再找用户代表或内容维护人（待指定） | 场景 ID、操作步骤、实际输出 |
| 内容错误 | 内容维护人（待指定）；涉及业务规则时升级业务 Owner（待指定） | 错误输出、对应来源材料、期望结果 |
| 客户适配调整 | 内容维护人（待指定）在允许范围内处理 | 变更内容、影响场景、Owner 确认 |
| Skill/代码修改 | 项目 FDE 评估 | 变更目的、影响范围、是否涉及核心边界 |
| 新场景需求 | 重新从需求探究开始，由项目 FDE 评估 | 业务任务、触发、期望结果 |

## 3. 问题提交最小信息

- 场景 ID：如 SCN-INQUIRY-INTAKE
- 操作步骤：用户做了什么、在哪一步
- 输入材料：提供的消息清单或记录（脱敏后）
- 实际输出：WorkBuddy 给出的结果
- 期望输出：业务上正确的结果

## 4. 允许与不允许分享的材料

| 类别 | 内容 |
|---|---|
| 允许分享 | 脱敏后的输入输出、错误现象描述、场景文档引用位置 |
