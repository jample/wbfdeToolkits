# inquiry-intake：询盘接收与首次行动辅助

## 能力
- 从用户粘贴或授权入口提供的未读消息生成当日待处理询盘清单，每条保留来源引用与接收时间。
- 按公司名、邮箱比对给出查重候选与命中理由；对不上时补充国家、产品、历史沟通线索；只展示候选，不合并、不下结论。
- 提示首次行动四项记录齐备性（客户确认了什么、承诺回复什么、内部要找谁、下次什么时候联系）。

## 边界
- 不自动合并客户记录；不自定有冲突的客户归属；未经对应负责人确认不承诺价格/交期；不自动写回、不自动外发回复。
- 依赖：无外部系统依赖；消息与客户历史记录由销售在会话中提供（系统接口未取得，降级为人工提供）。
