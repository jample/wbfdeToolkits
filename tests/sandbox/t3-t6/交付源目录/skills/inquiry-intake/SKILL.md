# inquiry-intake（沙盒模拟客户交付 Skill）

1. 从授权入口列出未读询盘消息；系统未接入时由销售手工提供消息清单。
2. 每条消息保留来源引用（EvidenceRef：消息 ID、接收时间、原文位置），不回原文不下结论。
3. 查重只展示候选与命中理由，不合并、不下结论；查重结论由销售人工确认。
4. 首次行动四项记录：客户确认内容、承诺回复、内部对接人、下次联系时间；缺项显式提示。
5. 回复只生成草稿，不自动外发；写回一律人工确认后执行。
