# 对话缩影：名称+概要 → 骨架落盘 → 幂等复跑

展示 fde-init 的典型对话：FDE 给出最小输入，Skill 连续执行 I1–I3 建立骨架；重复执行时不重复创建、不覆盖既有内容。

- I2：目标目录无既有内容，创建 00–07 骨架；`00_项目总览/项目总览.md` 填入三项已知信息、其余章节标"待补"；`交付计划.md` 按空白模板落盘；01–07 各阶段目录写入 README 占位。

> - 已创建：`00_项目总览/项目总览.md`（已填名称、概要、客户简称）、`00_项目总览/交付计划.md`（空白模板）、01–07 各阶段目录及 README 占位。

> - 下一步：提供业务背景后用 `fde-discovery-prepare` 开始访前准备，产物将写入 `01_预检/访前准备.md`。
