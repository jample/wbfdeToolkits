| 文件 | 类型 | 来源说明 |
|---|---|---|
| [interview-input.md](interview-input.md) | 输入示例 | 原话（`SALES-01–04`）来自跨境电商销售访谈原件；章节结构按 Simple v0.6 访谈输入模板重组 |
| [task-observation-input.md](task-observation-input.md) | 输入示例 | 步骤事实来自跨境电商销售任务回放原件；按任务观察输入模板重组，观察事实与推断分开 |
| [角色与场景总览.md](角色与场景总览.md) | 输出示例 | 业务结论来自 confirmed/ 下角色确认与场景总表；按 Simple v0.6 总览模板重组的教学表达 |
| [scene-requirement.md](scene-requirement.md) | 输出示例 | 业务结论来自询盘 scene-requirement.md confirmed 原件（§1–§8）；按 Simple v0.6 需求模板重组 |
| [dialogue-walkthrough.md](dialogue-walkthrough.md) | 对话示例 | 按设计文档 5.7、12 节 B1–B6 补问示例和 14.1/14.2 轮次 2–5 编写；"FDE 补充"是示范回答，不是新取得的客户确认 |
