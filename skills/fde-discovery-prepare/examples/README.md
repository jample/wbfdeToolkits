# fde-discovery-prepare 示例说明

按设计文档 Simple v0.6 第 10.4 节的例子来源约定：

- 示例的**业务内容**来自跨境电商既有实例原件（`fde跨境电商/01_预检/` 下的 industry-profile-source.md、contact-list.md、roles-day-hypo.md、scensoverview.md、SCN-INQUIRY-TRIAGE/scene-hypo.md、material-request-list.md、interview-plan.md）。
- 本目录的**文件表达**是按 Simple v0.6 模板重组的教学表达，并非声称原文件逐字如此。
- 示例中出现的"FDE 补充"是示范回答，不是新取得的客户确认；实际执行时必须记录真实收到的补充。
- 示例只作方法指导，不作为其他客户项目的事实来源。
