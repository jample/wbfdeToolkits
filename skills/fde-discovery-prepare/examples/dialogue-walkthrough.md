# 对话缩影：一句背景 → 访前准备初稿 → 补问 → 增量修订

基于设计文档 Simple v0.6 第 4.4 节对话例子和第 14.1/14.2 节轮次 1–2 整理。展示本 Skill 的一轮完整对话：FDE 每次只给增量，Skill 连续执行 A1–A4，定向补问后做增量修订。每轮标注更新的目标文件章节。

## 轮 1：一句背景 → 初稿

> **FDE**：这是一家卫浴跨境销售企业，希望了解销售与运营处理询盘和持续跟进的工作，帮我准备首次客户访谈。项目目录是 `<项目目录>`。

Skill 连续执行 A1–A4，创建 `<项目目录>/01_预检/访前准备.md`，尽量一次完成 §1–§6：

- A1 → §1：业务背景（卫浴跨境销售，销售/运营/经理协同）、本轮意图（询盘接收与持续跟进）、暂不展开（报价、库存、订单只留线索）、待了解（规模、入口、耗时）。
- A2 → §2–§3：销售、电商运营、区域经理三个角色假设（全部假设语气）和典型工作日假设。
- A3 → §4：候选场景 `SCN-INQUIRY-TRIAGE`（询盘识别与分派）、`SCN-SALES-FOLLOWUP`（持续跟进），关键未知"运营'分派'是转交还是决定 Owner"。
- A4 → §5–§6：三条资料请求（脱敏询盘、正常/疑似重复样例、行动样例）和三步访谈计划（运营+销售联合回放 → 销售演示 → 经理例外）。

Skill 回复（节选）：

> 已创建访前准备初稿，状态"草稿"。角色和场景均为假设，标注待核验。资料未说明"分派"具体由谁完成——这影响 §2 角色职责和 §4 场景假设。两个高影响问题：
> 1. 本轮是了解整个销售周期，还是优先了解询盘与跟进？
> 2. 能否邀请销售和运营一起回放同一条消息的接收过程？哪些岗位本轮可参与访谈？

## 轮 2：补问答复 → 增量修订

> **FDE**：可以安排销售和运营联合回访，经理能说明归属例外。本次先关注询盘和跟进，报价暂缓。

Skill 做增量修订，只更新受影响章节，保留其余内容：

- §1 本轮意图与暂不展开：确认"先关注询盘与跟进，报价保留线索"——记为本轮 FDE 范围选择；
- §2 联系人与角色假设：三个岗位均确认可参与，经理的可核验内容限定为归属例外；
- §4 候选场景：询盘、跟进列为优先展开，报价移出本轮展开范围；
- §6.1 访谈计划：按可参与对象落定三步安排；§6.3 记录本轮输入、更新章节和仍未解决的"分派"含义冲突。

Skill 回复（节选）：

> 已更新 §1、§2、§4、§6（其余章节未动）。输出状态提升为"有条件可用"：四条质量门已通过，可据此组织首次访谈。"分派"的业务含义保留为 §6.2 待补项，由联合回放核验。下一步：按计划取得纪要与观察记录，交给 fde-discovery-capture 核验假设——访谈计划本身不是已发生的访谈记录。
